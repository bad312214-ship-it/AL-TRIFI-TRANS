# 🎬 TRIFI Cinema Studio — استوديو تريفي للأفلام الذكية

منصة احترافية تحوّل **الفكرة أو النص** إلى **فيلم قصير متكامل** (حتى 5 دقائق) بالعربية
والإنجليزية: سيناريو مترابط → مشاهد ولقطات → شخصيات ثابتة الهوية → فيديو → صوت
وحوار → موسيقى → ترجمة → مونتاج → ملف MP4 جاهز للتنزيل.

> **صدّق المُخترعين، لا الشعارات:** كل زر في الواجهة موصول بوظيفة حقيقية. المحركات
> المحلية تُنتج ملفات فعلية بدون إنترنت، ومزودات الذكاء الاصطناعي الخارجي (OpenAI /
> Replicate / fal / Stability / ElevenLabs) متكاملة فعليًا وتُفعَّل بمفاتيح API في
> الإعدادات. لا توجد بيانات تجريبية تدّعي أن التوليد يعمل. راجع `docs/PROVIDERS.md`.

---

## ✨ المزايا

- 🧠 **سيناريو ذكي:** تحليل الفكرة → قصة ثلاثية الفصول → مشاهد ولقطات بزوايا كاميرا ومدد
- 🎭 **ثبات الشخصيات:** بطاقات مرجعية تُستخدم في كل المشاهد وإعادة استخدامها عبر المشاريع
- 🖼 **قصة مصوّرة (Storyboard):** مراجعة كل مشهد بصريًا وإعادة توليد مشهد واحد دون غيره
- 🎥 **توليد متعدد المقاطع:** كل لقطة تُولَّد ثم تُجمَّع بذكاء (لا ادعاء توليد 5 دقائق دفعة واحدة)
- 🎙 **صوت وحوار:** تعليق صوتي + حوارات شخصيات + موسيقى تصويرية + مؤثرات
- 📝 **ترجمة تلقائية:** حرق الترجمة داخل الفيديو + ملف SRT منفصل + بطاقات افتتاحية/ختامية
- 💰 **تقدير التكلفة قبل التوليد** + سجل مهام مع إعادة محاولة واستئناف بعد التوقف
- 🌐 **واجهة عربية RTL + إنجليزية**، داكنة وسينمائية، متجاوبة مع الهاتف والكمبيوتر
- 🔌 **طبقة مزودين قابلة للاستبدال** — تغيير مزوّد لا يتطلب إعادة بناء التطبيق
- 🔒 **مفاتيح API على الخادم فقط** (مُقنَّعة في الواجهة)، وحماية اختيارية بـ Token

## 🏗 البنية

```
frontend/            واجهة SPA (عربية RTL / إنجليزية)
backend/app/
  api/               مسارات HTTP + SSE للأحداث المباشرة
  providers/         مزودو AI (local | openai | replicate | fal | stability | elevenlabs)
  services/          pipeline · jobs · assembly(ffmpeg) · screenplay · costs
  models.py          SQLite: مشاريع، مشاهد، شخصيات، مهام، إعدادات
media/               المخرجات (صور، مقاطع، صوت، الفيلم النهائي)
docs/                المعمارية · المزودون · التشغيل
tests/               اختبارات شاملة حتى إنتاج MP4 فعلي
```

## 🚀 التشغيل السريع

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

افتح `http://localhost:8000` — يعمل فورًا بالمحركات المحلية المجانية.
لاستخدام مزودات الذكاء الاصطناعي المتقدمة: `cp .env.example .env` وأضف المفاتيح
(تفاصيل كاملة في `docs/SETUP.md` و`docs/PROVIDERS.md`).

## 🧪 الاختبار

```bash
.venv/bin/python -m pytest tests/ -q
```

اختبار E2E حقيقي: فكرة بالعربية → سيناريو → توليد مشاهد → مونتاج → **ملف MP4 + SRT**
على القرص → إعادة توليد مشهد → التحقق من استمرارية المشروع.

## ⚙️ المتطلبات الخارجية (عند رغبتك بالجودة القصوى)

| الخدمة | تُستخدم لـ | متغير البيئة |
|---|---|---|
| OpenAI (أو متوافق) | كتابة السيناريو + صور + TTS | `LLM_API_KEY` / `OPENAI_API_KEY` |
| Replicate | صور Flux + فيديو Kling/Wan | `REPLICATE_API_TOKEN` |
| fal.ai | فيديو Kling/Veo | `FAL_KEY` |
| Stability AI | صور SD3 | `STABILITY_API_KEY` |
| ElevenLabs | أصوات احترافية | `ELEVENLABS_API_KEY` |

بدون أي مفتاح يبقى المنتج عاملًا بالكامل (معاينة Animatic سينمائية + سيناريو + صوت مُزامن + ترجمة).
