# 07 · قواعد التحقق (Validation Rules)

التحقق على ثلاث طبقات: **قاعدة البيانات** (قيود) ← **الخدمة** (منطق الأعمال) ← **الواجهة** (تجربة المستخدم).

## 1. طبقة قاعدة البيانات

| القيد | الجدول | الأثر |
|---|---|---|
| `UNIQUE(advance_no)` | advances | لا تكرار لرقم العهدة |
| `UNIQUE(transfer_no)` | transfers | لا تكرار لرقم العملية |
| `UNIQUE(bank_ref) WHERE bank_ref IS NOT NULL AND is_void=0` | transfers | لا تكرار للمرجع البنكي |
| `UNIQUE(settlement_no)` | advance_settlements | لا تكرار لرقم الإخلاء |
| `UNIQUE(advance_id, invoice_no) WHERE is_void=0` | advance_settlements | لا تكرار لفاتورة الإخلاء على نفس العهدة |
| `UNIQUE(supplier_id, invoice_no)` | supplier_invoices | لا تكرار لفاتورة المورد |
| `UNIQUE(payment_no)` | payments | لا تكرار لرقم الدفعة |
| `UNIQUE(ref_type, ref_id) WHERE is_void=0` | journal_entries | قيد واحد لكل عملية |
| `CHECK(amount > 0)` | transfers, advances, payments | لا مبالغ صفرية/سالبة |
| `CHECK(net_amount >= 0 AND vat_amount >= 0)` | settlements, invoices | لا قيم سالبة |
| `CHECK(... IN (...))` | كل حقول الحالة | قيم حالات مضبوطة |
| `NOT NULL` | الحقول الإلزامية | لا اعتماد ناقص |
| `FOREIGN KEY ... ON DELETE RESTRICT` | كل العلاقات | لا حذف سجل مرتبط |

## 2. طبقة الخدمات — قواعد عامة

| القاعدة | الرسالة | الرمز |
|---|---|---|
| `reqStr` | «حقل "X" مطلوب» | 400 VALIDATION |
| `reqDate` (YYYY-MM-DD) | «صيغة "X" غير صحيحة» | 400 |
| `reqMoney` (> 0) | «"X" يجب أن يكون أكبر من صفر» | 400 |
| `oneOf` | «قيمة "X" غير مسموحة» | 400 |
| `mustExist` | «X غير موجود» | 400 |
| مركز التكلفة يجب أن يتبع المشروع | «مركز التكلفة لا يتبع المشروع المحدد» | 400 |

## 8. المرفقات

| القاعدة |
|---|
| الامتدادات المسموحة: jpg, jpeg, png, webp, gif, heic, pdf, doc, docx, xls, xlsx, txt |
| أنواع المحتوى مقيّمة بقائمة بيضاء (MIME whitelist) |
| الحد الأقصى للحجم: 15 ميجابايت (قابل للضبط بـ `MAX_UPLOAD_MB`) |
| اسم التخزين يُولَّد عشوائيًا (لا مسار من اسم الملف الأصلي) |
| الحذف = تعليم بـ `is_void` مع سبب |

## 9. المستخدمون والصلاحيات

| القاعدة |
|---|
| اسم المستخدم: 3–60 حرفًا إنجليزيًا/أرقامًا/`. _ -`، فريد |
| كلمة المرور: 8 أحرف على الأقل، مخزّنة بـ bcrypt |
| تغيير كلمة المرور يتطلب الكلمة الحالية |
| إعادة التعيين تُبطل كل جلسات المستخدم وتفعّل `must_change_password` |
| الدور يجب أن يكون موجودًا |

## 10. طبقة الواجهة

- حقول مطلقة مميزة بـ `*` و`required`.
- حساب الإجمالي (صافي + ضريبة) لحظيًا في إخلاء العهد وفواتير الموردين.
- عرض الرصيد المتاح والرصيد بعد الإخلاء **قبل** الحفظ، مع تحذير أحمر عند التجاوز.
- منع النقر المزدوج بتعطيل الأزرار أثناء الحفظ.
- حوارات تأكيد لكل إجراء غير قابل للتراجع (إلغاء، إغلاق، حذف مرفق، تطهير السجلات).
