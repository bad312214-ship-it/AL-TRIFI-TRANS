# 06 · بنية الواجهة (Frontend Structure)

## 1. التقنية

- **Vanilla JS** (بلا إطار عمل ولا CDN) → تعمل في شبكة معزولة وبإقلاع فوري.
- **Hash Router** (`#/advances?status=open`) → لا يحتاج إعادة توجيه من الخادم.
- **CSS Variables** لنظام التصميم → تبديل فوري بين الوضع الفاتح والليلي.
- **رسوم SVG/CSS خالصة** (Donut / Bars / Columns) → بلا مكتبات خارجية.

## 4. مكوّنات الواجهة

### بطاقة KPI
```
┌─┬──────────────────────────┐
│▌│ 🧾  إجمالي عهد المقاولين │
│ │ 88,000.00 ريال           │
│ │ 3 عهدة                   │
└─┴──────────────────────────┘
```
شريط لوني جانبي يتغير حسب طبيعة المؤشر (أزرق/أخضر/كهرماني/أحمر).

### الجدول
- رأس لاصق (sticky) أثناء التمرير.
- ترتيب بالنقر على الأعمدة المسموحة (`sortable`) مع مؤشر ▲▼.
- صفوف قابلة للنقر لفتح البطاقة، وأزرار إجراءات مستقلة.
- صف إجماليات في `tfoot` بخط مزدوج.
- ترقيم صفحات + اختيار عدد السجلات (20/50/100/200).

### البطاقة الكاملة (Modal بتبويبات)
شريط أرصدة علوي (المبلغ / المُخلى / المعلّق / المتبقي / الحالة) ثم تبويبات:
التفاصيل · الإخلاءات · التحويلات · المرفقات · سجل العمليات · القيد المحاسبي.

### النماذج
- تُبنى من تعريف dichiarativo (`formHTML`) مع أقسام (`section`).
- تحقق من جهة الخادم مع إبراز الأخطاء، وحوارات خاصة لحالات 409:
  - `OVER_SETTLEMENT` → حوار «تجاوز رصيد العهدة» مع checkbox تأكيد (يظهر فقط لمن يملك الصلاحية).
  - `DUPLICATE_TRANSFER` → جدول بالتحويلات المطابقة.
  - `UNSETTLED_BALANCE` → رسالة تنبيه.

### الفلاتر
شريط قابل للطي، يُطبَّق تلقائيًا عند تغيير القوائم المنسدلة والتواريخ، مع زر «مسح».
كل الفلاتر تُحفظ في الـ URL → يمكن مشاركة الرابط أو تحديث الصفحة دون فقدان الحالة.

### البحث الشامل
بحث واحد في 8 وحدات (عهد، تحويلات، إخلاءات، فواتير، دفعات، مقاولون، موردون، سجل العمليات)
مع تجميع النتائج وانتقال مباشر للسجل.

## 5. التصميم

| العنصر | القيمة |
|---|---|
| اللون الأساسي | `#1f3a5f` (كحلي مؤسسي) |
| اللون المميّز | `#0f766e` (أخضر مزرق) |
| النجاح / التحذير / الخطر | `#15803d` / `#b45309` / `#b91c1c` |
| نصف قطر | 12px للبطاقات، 8px للحقول |
| الخط | Segoe UI / Noto Naskh Arabic |
| الوضع الليلي | `[data-theme="dark"]` — محفوظ في localStorage |
| التجاوب | كسر عند 1024px (قائمة منزلقة) و640px (شبكة مضغوطة) |
| الطباعة | `@media print` يُخفي القوائم ويُظهر الجداول فقط |
