# دليل مزودي الذكاء الاصطناعي — المقارنة والتكامل

طبقة المزودين في `backend/app/providers/` تجعل استبدال أي مزوّد عملية محلية واحدة
(واجهة `LLMProvider / ImageProvider / VideoProvider / TTSProvider / MusicProvider`).

## المُفعَّل حاليًا (مُختبر فعليًا بدون مفاتيح)

| المهمة | المحرك المحلي | ما ينتجه فعليًا |
|---|---|---|
| كتابة السيناريو | `LocalPlanner` | خطة مشاهد/لقطات/شخصيات مترابطة ثلاثية الفصول من فكرة المستخدم |
| الصور | `LocalImageProvider` | لوحات Concept Art سينمائية (تدرّجات، جبال، ضباب، ظلال، حبيبات فيلم) |
| الفيديو | `LocalVideoProvider` | مقاطع MP4 حقيقية بحركة كاميرا (Ken Burns) فوق صور المشاهد |
| الصوت | `LocalTTSProvider` | espeak-ng إن وُجد، وإلا مسار صوتي صامت مُزامن مع الترجمة |
| الموسيقى | `LocalMusicProvider` | موسيقى أجواء WAV (تدرّجات وترية + LFO) حسب المزاج |

## المزودون الخارجيون (كود تكامل جاهز — يحتاج مفاتيح)

### كتابة السيناريو (LLM)
| المزود | النموذج المقترح | ملاحظات |
|---|---|---|
| **OpenAI** | `gpt-4o-mini` / `gpt-4o` | الأفضل في فهم البنية السينمائية، JSON mode |
| **أي نقطة نهاية متوافقة** | Ollama / LM Studio / Groq | غيّر `LLM_BASE_URL` فقط — يعمل محليًا 100% |

### توليد الصور (الشخصيات والبيئات)
| المزود | النموذج | الدقة | ملاحظات |
|---|---|---|---|
| **OpenAI Images** | dall-e-3 / gpt-image-1 | حتى 1792×1024 | ممتاز للاتساق البصري مع وصف دقيق |
| **Replicate** | Flux 1.1 Pro | حتى 2K | جودة عالية، تكلفة معقولة (~$0.04/صورة) |
| **Stability AI** | Stable Image Core | حتى 1536×1024 | تحكم جيد بالـseed (ثبات الشخصيات) |

### توليد الفيديو
| المزود | النموذج | مدة المقطع | ملاحظات |
|---|---|---|---|
| **Replicate** | Kling 2.1 / Wan 2.2 / Minimax | 5–10 ثوانٍ | يدعم Image-to-Video (بداية من إطار الشخصية = اتساق أعلى) |
| **fal.ai** | Kling / Veo 3 | 5–10 ثوانٍ | استجابة سريعة، Veo 3 يولّد صوتًا أحيانًا |

> **قاعدة واقعية:** لا توجد خدمة تنتج فيلم 5 دقائق بطلب واحد. المنصة مصممة أصلًا
> لتوليد **مقاطع قصيرة لكل لقطة** ثم تجميعها محليًا مع الحفاظ على الترابط البصري
> (نفس بطاقة الشخصية، نفس بطاقة البيئة، نفس الـseed).

### الأصوات (TTS)
| المزود | اللغات | ملاحظات |
|---|---|---|
| **OpenAI TTS** | عربي/إنجليزي/متعدد | أصوات طبيعية (alloy, nova…) |
| **ElevenLabs** | متعدد (eleven_multilingual_v2) | أفضل نطق عربي وأدلة مشاعر |
| **espeak-ng** | عربي/إنجليزي | مجاني محليًا — جودة آلية مقبولة للمعاينات |

### مزامنة الشفاه (Lip Sync) — خارطة الطريق
تتطلب خدمات متخصصة (HeyGen, Sync Labs, D-ID). الواجهة معدّة لإضافتها كمزود
`LipSyncProvider`؛ غير مُفعَّلة حاليًا لعدم توفّر مفاتيح — **لا ندّعي عملها**.

## اختيار المنصة حسب الحالة

| حالتك | الإعداد المقترح |
|---|---|
| بدون أي مفتاح (وضع المعاينة) | كل المحركات `local` — فيلم كامل مجاني بالكامل |
| جودة قصوى | LLM: gpt-4o · صور: Flux · فيديو: Kling (Replicate) · صوت: ElevenLabs |
| تكلفة منخفضة | LLM: gpt-4o-mini · صور: local أو Flux · فيديو: local animatic · صوت: OpenAI TTS |
| بيانات خاصة/محلي | Ollama + SD محلي + Piper — كل شيء داخل شبكتك (غيّر `LLM_BASE_URL`) |

## الحدود المُصرَّح بها
- 4K: مدعوم في الصور والتجميع؛ مزودات الفيديو التوليدية غالبًا 720p/1080p فقط (الواجهة تعرض ما يدعمه كل مزود فعليًا).
- 60fps: مدعوم في التجميع المحلي؛ المزودات التوليدية غالبًا 24/30fps.
- المدة: حتى 5 دقائق (300 ثانية) — عبر توليد مقاطع وتجميعها، كما هو موثّق أعلاه.
