# 04 · المنطق المحاسبي (Accounting Logic)

## 1. معادلة الرصيد الأساسية

```
الرصيد المتبقي للعهدة = مبلغ العهدة − مجموع فواتير الإخلاء المعتمدة
```

- الإخلاءات **المعتمدة** فقط تُنقص الرصيد.
- الإخلاءات **المعلّقة** تُحتسب ضمن «الرصيد المحتجز» لمنع الإفراط في الإخلاء قبل الاعتماد.
- الإخلاءات **المرفوضة/الملغاة** لا أثر لها.

```js
// server/services/advances.service.js → getBalance()
remaining = round2(amount - approved_total)
reserved  = round2(amount - approved_total - pending_total)
```

## 2. اشتقاق حالة العهدة تلقائيًا

```js
// deriveStatus()
if (رصيد ≤ 0.005)                     → closed            (مغلقة)
else if (إخلاءات معلّقة > 0)          → under_settlement  (تحت الإخلاء)
else if (إجمالي المُخلى > 0)          → partially_closed  (مغلقة جزئيًا)
else                                  → open              (مفتوحة)
```

يُعاد الاشتقاق بعد كل عملية تؤثر على الإخلاءات (`refreshStatus`).
إذا أغلق المستخدم العهدة يدويًا تُثبَّت الحالة بـ `status_locked_by_user = 1`.

## 3. حالات فاتورة المورد

```
paid_total = Σ الدفعات المعتمدة غير الملغاة على الفاتورة
paid_total ≤ 0.005                     → unpaid   (غير مدفوعة)
paid_total ≥ total − 0.005             → paid     (مدفوعة بالكامل)
غير ذلك                                → partial  (مدفوعة جزئيًا)
```

## 5. قواعد الترحيل الآلي (Posting Rules)

| العملية | مدين | دائن |
|---|---|---|
| اعتماد تحويل **عهدة** | 1200 عهدي المقاولين (أو الحساب المحدد) | حساب مصدر التمويل (2100/2400/2500) |
| اعتماد تحويل **مورد** | 1300 دفعات مقدمة للموردين | حساب مصدر التمويل |
| اعتماد تحويل **آخر** | 4100 مصاريف المشاريع | حساب مصدر التمويل |
| اعتماد **إخلاء عهدة** | حساب المصروف (صافي) + 1400 ضريبة المدخلات | 1200 عهدي المقاولين (الإجمالي) |
| اعتماد **فاتورة مورد** | حساب المصروف (صافي) + 1400 ضريبة المدخلات | 2200 حسابات الموردين (الإجمالي) |

- يُرفض القيد إذا لم يتوازن (`مدين ≠ دائن`).
- عند إلغاء الاعتماد أو إلغاء العملية: `voidEntriesFor(refType, refId)` تُعلَّم القيود بـ `is_void = 1`.
- القيد الفريد مضمون بفهرس جزئي `ux_journal_ref (ref_type, ref_id) WHERE is_void = 0`.

### مثال حقيقي من بيئة الاختبار

```
اعتماد تحويل TRF-2026-0001 (50,000 من جاري الشريك):
   1200 عهدي المقاولين      50,000 مدين
   2100 جاري الشركاء                 50,000 دائن

اعتماد إخلاء 20,000 على العهدة:
   4110 مصاريف أعمال مدنية   20,000 مدين
   1200 عهدي المقاولين                20,000 دائن

ميزان المراجعة الناتج:  مدين 227,300 = دائن 227,300  ✓
```

## 6. تحليل مصادر التمويل

لكل مصدر:

```
total_transfers  = Σ التحويلات المعتمدة غير الملغاة
to_advances      = Σ التحويلات المعتمدة من نوع advance
to_suppliers     = Σ التحويلات المعتمدة من نوع supplier
to_other         = Σ التحويلات المعتمدة من نوع other
pending_transfers= Σ التحويلات المعلّقة (مسودة/بانتظار الاعتماد)
remaining_limit  = credit_limit − total_transfers   (إن وُجد سقف)
```

## 7. تقرير المقاولين

```
إجمالي العهد      = Σ مبالغ العهد المعتمدة غير الملغاة
إجمالي التحويلات  = Σ التحويلات المعتمدة للمقاول
إجمالي الإخلاءات  = Σ الإخلاءات المعتمدة (الإجمالي شامل الضريبة)
إجمالي المصروفات  = Σ الإخلاءات المعتمدة (الصافي قبل الضريبة)
الرصيد المتبقي    = إجمالي العهد − إجمالي الإخلاءات
العهد المفتوحة/المغلقة = عدد حسب الرصيد
```

## 8. تقرير الموردين

```
إجمالي الفواتير = Σ الفواتير المعتمدة غير الملغاة
المدفوع         = Σ الدفعات المعتمدة
المستحق         = إجمالي الفواتير − المدفوع
```

## 10. ضريبة القيمة المضافة

- تُدخل كقيمة مطلقة، والنظام يتحقق: `الإجمالي = الصافي + الضريبة` (بعتبة 0.005).
- الواجهة تقترح 15% تلقائيًا عند إدخال الصافي، مع إمكانية التعديل.
- الضريبة تُرحَّل إلى حساب 1400 (ضريبة المدخلات) في الإخلاءات وفواتير الموردين.
