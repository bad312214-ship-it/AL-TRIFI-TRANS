# التشغيل والإعداد

## المتطلبات
- Python 3.11+
- (اختياري) espeak-ng لصوت محلي حقيقي: `sudo apt install espeak-ng`
- لا حاجة لتثبيت ffmpeg — يُنزَّل تلقائيًا عبر `imageio-ffmpeg`

## خطوات التشغيل

```bash
# 1. البيئة الافتراضية والحزم
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt

# 2. الإعدادات (اختياري — بدونها يعمل كل شيء محليًا)
cp .env.example .env   # ثم أضف المفاتيح إن وُجدت

# 3. التشغيل
.venv/bin/python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

افتح المتصفح على `http://localhost:8000` (أو منفذ المنصة المعروض).

## الاختبارات

```bash
.venv/bin/python -m pytest tests/ -q
```

تشمل اختبارًا شاملًا: فكرة → سيناريو → فيلم MP4 فعلي → إعادة توليد مشهد.

## ملاحظات الإنتاج
- البيانات في `data/trifi.db` والوسائط في `media/` (كلاهما في `.gitignore`).
- لإعادة استكمال مشروع متوقف: أعد تشغيل الخادم — تُجدول المهام المعلّقة تلقائيًا،
  أو اضغط «استكمال الإنتاج» في تبويب الإنتاج.
- لحماية الخادم على شبكة: ضع `APP_API_TOKEN` في `.env` (يُرسل عبر ترويسة Authorization).
- مفاتيح API لا تُكتب في الواجهة ولا تُحفظ في Git — فقط في `.env` أو جدول الإعدادات على الخادم.
